# Volugia — Site officiel (volugia.me)

Site vitrine présentant l'application Volugia : bibliothèque personnelle et lecteur de mangas, BD et livres numériques pour Windows et Android.

## Structure
- `index.html` : page principale présentant l'application, ses fonctionnalités, sa galerie et son guide de démarrage.
- `style.css` : feuille de styles responsive (palette sombre officielle Volugia, variables CSS, typographie fluide).
- `main.js` : interactions légères (menu mobile, onglets accessibles de la galerie).
- `assets/` : captures d'écran réelles (Windows et Android), icône et police `Dancing Script`.
- `downloads/` : exécutable et APK pour l'installation directe.
- `CNAME` : domaine `volugia.me`.

## Aperçu local
Ouvrir directement `index.html` dans un navigateur ou lancer un serveur local :

```powershell
python -m http.server 8000
```
