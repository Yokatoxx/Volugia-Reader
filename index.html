Une bibliothèque conçue pour respecter vos fichiers

Contrairement aux plateformes dépendantes du cloud, Volugia place votre autonomie au centre. Vous possédez vos livres, votre matériel et vos données.

Le PC héberge votre bibliothèque sur votre réseau local. Votre téléphone Android s'y associe d'un geste pour lire en streaming local ou télécharger vos tomes pour vos déplacements.

APPLICATION WINDOWS

Votre collection classée sans effort, sans toucher à vos fichiers

Ajoutez simplement le dossier de votre disque contenant vos BDs et mangas. Volugia parcourt les sous-dossiers et organise automatiquement votre collection par séries.

  • Couverture automatique du tome 1 : Reconnaissance intelligente des tomes (T01, Tome 1, V001, Vol 1) pour afficher la meilleure couverture.
  • Tolérant aux extensions : Même si une archive 7z ou RAR est renommée .cbz, Volugia identifie son format interne réel.
  • Non destructif : Vos fichiers originaux ne sont jamais altérés, extraits sur le disque ou déplacés.
  • Reprise rapide : La rangée « Continuer la lecture » affiche immédiatement votre position et la barre de progression.
APPLICATION ANDROID NATIVE

Un lecteur mobile pensé pour les passionnés de BD et mangas

Emportez vos lectures au creux de la main. L'application Android offre une interface Java native et un lecteur taillé pour une fluidité absolue.

  • Sens de lecture mémorisé : Lecture japonaise (droite à gauche) ou occidentale, retenue par livre.
  • Modes de pages : Plein écran, page simple, double page manuelle ou détection automatique de double planche.
  • Téléchargement hors-ligne : Conservez des tomes ou des séries entières sur votre téléphone pour lire en voyage ou dans l'avion.
  • Révélation circulaire : Un suivi élégant du pourcentage de téléchargement directement sur la couverture, sans animation gourmande.
  • Passage de tome instantané : Deux touches en fin de tome pour ouvrir immédiatement le suivant.
LIAISON & SYNCHRONISATION

Appairage en 5 secondes et synchronisation transparente

Oubliez les configurations réseau complexes, les ouvertures de ports ou les adresses IP à retenir. Volugia gère tout de manière sécurisée et invisible.

  • Découverte automatique (mDNS) : Le téléphone détecte automatiquement le PC sur votre réseau Wi-Fi local.
  • Code temporaire à 12 caractères : Un code d'association unique permet d'authentifier le certificat TLS local.
  • Chiffrement robuste : Sessions protégées avec Windows DPAPI sur PC et Android Keystore sur mobile.
  • Zéro requête au repos : Aucune boucle de synchronisation permanente en arrière-plan pour préserver l'autonomie.
  • Import de progressions : Récupérez votre historique de lecture depuis YACReader, Calibre, Komga ou Kavita en un clic.

PRISE EN MAIN

Comment démarrer en 3 étapes simples

Moins de 2 minutes suffisent pour configurer votre bibliothèque et commencer à lire sur tous vos écrans.

01

Ajoutez vos dossiers

Lancez Volugia.exe sur votre PC. Cliquez sur Ajouter un dossier et sélectionnez le répertoire contenant vos tomes. Vos sous-dossiers sont analysés automatiquement.

02

Reliez votre téléphone

Sur le PC, cliquez sur Mon espace → Mes appareils → Relier un téléphone. Sur Android, ouvrez l'application, sélectionnez le PC détecté et entrez le code de 12 caractères.

03

Lisez partout, hors ligne

Lisez confortablement sur votre moniteur ou lancez le téléchargement de vos séries sur Android pour les savourer n'importe où, même sans réseau.

FORMATS & COMPATIBILITÉ

Prise en charge universelle et sécurité moderne

Conçu pour s'adapter à vos fichiers existants sans nécessiter de conversion fastidieuse.

Formats de lecture supportés

  • CBZ (Archives ZIP) : Images ordonnées naturellement, prise en compte des métadonnées ComicInfo.xml.
  • CBR (Archives RAR) : Lecture directe grâce à UnRAR sans extraction intégrale sur le disque.
  • PDF : Rendu haute fidélité page par page avec couverture générée depuis la première page.
  • EPUB : Rendu à pagination fixe et stable pour préserver l'exactitude de vos marque-pages.
  • Archives 7z : Détectées et lues nativement même sous l'extension .cbz.

Sécurité & Architecture

  • Architecture locale : Exécutable Windows autonome avec Microsoft WebView2 et SQLite local.
  • Client Android natif : Code Java pur, sans WebView, optimisé pour l'autonomie et le rafraîchissement d'écran.
  • Chiffrement des sessions : Windows DPAPI pour la session PC, Android Keystore pour le mobile.
  • Transports chiffrés : Connexions sécurisées par certificat TLS local généré sur votre machine.
  • Comptes partagés optionnels : Hachage Argon2id, aucun mot de passe conservé en clair.
QUESTIONS FRÉQUENTES

Tout ce que vous souhaitez savoir sur Volugia

Des réponses claires et transparentes sur le fonctionnement de l'application.

Mes mangas et livres sont-ils envoyés sur Internet ?

Non, absolument jamais. Volugia est une application strictement « Local-First ». Vos fichiers restent sur votre PC et sont servis uniquement à votre téléphone via votre réseau Wi-Fi local (ou via un canal P2P direct et chiffré si vous activez l'accès distant). Aucun fichier n'est transmis à un serveur cloud.

Faut-il créer un compte pour utiliser Volugia ?

Non. Vous pouvez utiliser Volugia sur votre PC et relier votre téléphone Android via votre réseau local sans jamais créer de compte ni renseigner d'adresse e-mail. L'option de compte partagé (local ou Google) est strictement facultative et sert uniquement à faciliter la gestion de plusieurs appareils.

L'application fonctionne-t-elle sans connexion Internet ?

Oui, à 100%. Sur le PC, Volugia n'a besoin d'aucun accès Web pour fonctionner. Sur Android, dès lors que vous avez téléchargé vos tomes ou vos séries via le Wi-Fi, vous pouvez lire en mode avion, dans le train ou en pleine nature sans aucune connexion.

Volugia modifie-t-il ou renomme-t-il mes fichiers originaux ?

Non. Volugia ne modifie, ne renomme et n'extrait jamais vos archives sur le disque. Les métadonnées, séries et progressions sont enregistrées dans une base SQLite indépendante (data/library.sqlite). Si vous retirez un dossier de Volugia, vos fichiers originaux restent intacts à leur emplacement.

Puis-je récupérer mes lectures depuis YACReader, Komga ou Calibre ?

Oui ! Volugia intègre un outil de migration intelligent. Il détecte automatiquement les bases SQLite de YACReader, Calibre, Komga ou Kavita, prévisualise les correspondances avec vos livres et importe votre progression (pages lues, favoris, statuts) en créant une sauvegarde préalable automatique.

Quels sont les prérequis pour utiliser Volugia sur Windows ?

Il suffit de posséder Windows 10 ou 11 (64 bits) avec Microsoft WebView2 (déjà préinstallé par défaut sur la quasi-totalité des PC Windows). Vous n'avez pas besoin d'installer Python : Volugia.exe est un exécutable autonome qui intègre son propre environnement d'exécution.

Quelle version d'Android est requise ?

L'application Android est compatible avec Android 8.0 (Oreo) et toutes les versions ultérieures (jusqu'à Android 16). Elle est légère (moins de 200 Ko) et ne dépend d'aucun service tiers lourd.
