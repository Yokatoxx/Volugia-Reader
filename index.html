FORMATS & COMPATIBILITÉ

Vos formats. Vos fichiers. Votre choix.

Conçu pour s'adapter à vos fichiers existants sans nécessiter de conversion fastidieuse.

Formats de lecture supportés

  • CBZ (Archives ZIP) : Images ordonnées naturellement, prise en compte des métadonnées ComicInfo.xml.
  • CBR (Archives RAR) : Lecture directe grâce à UnRAR sans extraction intégrale sur le disque.
  • PDF : Rendu haute fidélité page par page avec couverture générée depuis la première page.
  • EPUB : Rendu à pagination fixe et stable pour préserver l'exactitude de vos marque-pages.
  • Archives 7z : Détectées et lues nativement même sous l'extension .cbz.
  • Webtoons : Lecture verticale continue, adaptée aux longues pages.

Sécurité & Architecture

  • Architecture locale : Exécutable Windows autonome avec Microsoft WebView2 et SQLite local.
  • Client Android natif : Code Java pur, sans WebView, optimisé pour l'autonomie et le rafraîchissement d'écran.
  • Chiffrement des sessions : Windows DPAPI pour la session PC, Android Keystore pour le mobile.
  • Transports chiffrés : Connexions sécurisées par certificat TLS local généré sur votre machine.
  • Comptes partagés optionnels : Hachage Argon2id, aucun mot de passe conservé en clair.
QUESTIONS FRÉQUENTES

Quelques questions, avant le premier tome.

Des réponses claires et transparentes sur le fonctionnement de l'application.

Faut-il créer un compte pour utiliser Volugia ?

Non. Vous pouvez utiliser Volugia sur votre PC et relier votre téléphone Android via votre réseau local sans jamais créer de compte ni renseigner d'adresse e-mail. L'option de compte partagé (local ou Google) est strictement facultative et sert uniquement à faciliter la gestion de plusieurs appareils.

L'application fonctionne-t-elle sans connexion Internet ?

Oui, à 100%. Sur le PC, Volugia n'a besoin d'aucun accès Web pour fonctionner. Sur Android, dès lors que vous avez téléchargé vos tomes ou vos séries via le Wi-Fi, vous pouvez lire en mode avion, dans le train ou en pleine nature sans aucune connexion.

Volugia modifie-t-il ou renomme-t-il mes fichiers originaux ?

Non. Volugia ne modifie, ne renomme et n'extrait jamais vos archives sur le disque. Les métadonnées, séries et progressions sont enregistrées dans une base SQLite indépendante (data/library.sqlite). Si vous retirez un dossier de Volugia, vos fichiers originaux restent intacts à leur emplacement.

Puis-je récupérer mes lectures depuis YACReader, Komga ou Calibre ?

Oui ! Volugia intègre un outil de migration intelligent. Il détecte automatiquement les bases SQLite de YACReader, Calibre, Komga ou Kavita, prévisualise les correspondances avec vos livres et importe votre progression (pages lues, favoris, statuts) en créant une sauvegarde préalable automatique.

Quels sont les prérequis pour utiliser Volugia sur Windows ?

Il suffit de posséder Windows 10 ou 11 (64 bits) avec Microsoft WebView2 (déjà préinstallé par défaut sur la quasi-totalité des PC Windows). Vous n'avez pas besoin d'installer Python : Volugia.exe est un exécutable autonome qui intègre son propre environnement d'exécution.

Quelle version d'Android est requise ?

L'application Android est compatible avec Android 8.0 (Oreo) et toutes les versions ultérieures (jusqu'à Android 16). Elle est légère (moins de 200 Ko) et ne dépend d'aucun service tiers lourd.
